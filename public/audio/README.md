# Name pronunciation audio

Drop your recording here as:

  public/audio/onkar-sathe.mp3

How to make it (30 seconds):
1. Open a voice recorder on your phone.
2. Say "Onkar Sathe" clearly, once.
3. Export/share as MP3 and save it here with the exact name above.
4. Restart `npm run dev` (or redeploy) — the speaker button next to
   your name will play this file.

Until the file exists, the button falls back to the browser's
built-in voice reading "Onkar Sathe".
